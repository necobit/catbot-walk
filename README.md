# キャットボットのおさんぽ (Catbot Walk)

ちいさな球体の世界を Catbot が歩き回るだけの 3D ページです。
どうぶつの森のように、地平線が丸く転がる広角視点で眺められます。

- モデル: `Catbot_____1body.step`（本人の CAD モデル）を `convert.py` で GLB 化
  （色は STEP 内の COLOUR_RGB 定義＝黄 #E8AC22 / 赤 #C43527 / 鋼 #9F9F9F を再現）
- 世界のどこかに、半球ドームを載せた M5StopWatch のボールが置いてあります
- 操作: WASD・矢印キー / 画面左下スティック（タッチ）で移動、ドラッグでカメラ、
  ホイール・ピンチでズーム、スペース or タップでジャンプ
- 「おさんぽモード」ON の間は勝手に散歩します

Three.js (WebGL) 製。`index.html` と `catbot.glb` を同じ場所に置けば動きます。
